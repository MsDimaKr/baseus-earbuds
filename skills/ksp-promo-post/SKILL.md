# Промо-пост KSP

Пользователь ведёт русскоязычные каналы со скидками (WhatsApp/Telegram/Facebook) и получает партнёрскую комиссию от KSP. KSP присылает ему каждую акцию письмом на иврите; твоя задача — превратить письмо в пост, по которому русскоязычная аудитория захочет кликнуть: текст **и** яркую картинку. Пользователь может писать тебе на иврите или по-русски; содержимое поста — всегда на русском.

## 1. Найди и прочитай письмо

Загрузи инструменты Hotmail (`ToolSearch` → `select:mcp__Hotmail__search_emails,mcp__Hotmail__read_email`), затем ищи в INBOX с `from: "aff@ksp.co.il"` и `since` на несколько дней назад. Возьми самое новое письмо, которое ещё не обработано (если не уверен — проверь, нет ли в репозитории папки `ksp-<тема>-promo/`). Прочитай его полностью.

Для каждого товара вытащи: название на иврите → что это на самом деле, итоговую цену («ישלמו רק ₪X»), старую цену («במקום ₪Y»), партнёрскую ссылку на товар (`https://ksp.co.il/appkey/17585/item/<ID>`), а также ссылку на категорию / «все товары», процент доп. скидки, подарки и дату окончания («בתוקף עד»).

Обрати внимание:
- **Никогда не упоминай комиссию** («תגמול …% ממחיר המכירה») — это личный доход пользователя, подписчикам это не нужно.
- В письмах KSP бывают ошибки копирования (например, два разных товара с одинаковым названием «Elvive»). Если присланные фото противоречат письму — доверяй фото и скажи пользователю, что ты предположил. Если пользователь исправляет цену — просто примени исправление.

## 2. Напиши полный пост на русском

Следуй устоявшемуся стилю пользователя (см. `references/text-examples.md` — прочитай перед первым постом в сессии):

- Первая строка: эмодзи + бренды + «дополнительная скидка N% в KSP!». Затем одна строка-крючок и, если есть подарок, строка с 🎁.
- Группируй товары по сериям/брендам, если так сделано в письме (например, 🟢 зелёная серия / 🔵 синяя серия).
- Каждый товар: один подходящий эмодзи, короткое живое описание (переводи смысл, а не транслитерируй иврит), затем `Цена **X ₪** вместо Y ₪`, затем ссылка **отдельной строкой** после 👉.
- После товаров: ссылка(и) на категорию с 👉 отдельной строкой.
- Всегда заканчивай ровно так:
  `📅 Акции действуют до DD.MM.YYYY или до окончания запасов. Дополнительная скидка применяется при переходе по ссылкам и обновляется в корзине.`

Дай текст прямо в чате (файл не нужен) и в том же сообщении попроси фото товаров.

**Версия для WhatsApp** (когда просят сократить): жирная строка-заголовок, строка с подарком, затем по каждому товару только `эмодзи Название — *X ₪* вместо Y ₪` + ссылка с 👉, ссылка на все товары и одна строка `📅 До DD.MM.YYYY. Скидка — при переходе по ссылкам.` В WhatsApp жирный шрифт — `*одна звёздочка*`.

## 3. Получи фото товаров

KSP (ksp.co.il / img.ksp.co.il) отдаёт этой облачной среде ошибку Cloudflare 403 (IP дата-центра в США), поэтому скачать фото нельзя — не трать время на повторные попытки. Пользователь присылает фото в чат; они сохраняются как `/tmp/claude-0/<project>/<session>/images/N.jpg`.

- Смотри список через `ls <папка-images> | sort -V | tail` и сопоставляй каждый новый файл с товаром, **посмотрев на него** (Read) — порядок отправки не гарантирован, а фото, показанное в чате, иногда ещё не сохранено на диск. Если фото нет — отрендерь без него и попроси пользователя прислать ещё раз.
- Копируй в `src/` акции с понятными именами (`bosch-xline-173.jpg`). Если на фото есть наклейка/бейдж на иврите — обрежь её через PIL.

## 4. Собери картинку

Создай в корне репозитория папку `ksp-<тема>-promo/` с `src/` (фото товаров + `ksp-logo.png` из `assets/` этого скилла) и `config.json`, затем отрендерь:

```bash
NODE_PATH=$(npm root -g) node <папка-скилла>/scripts/render.js ksp-<тема>-promo
```

Скопируй `scripts/render.js` и в папку акции, чтобы она была самодостаточной в репозитории. Формат конфига — см. два готовых примера:
- `references/config-example.json` — раскладка **rows**: 2 подписанных раздела × 3 карточки (две серии/бренда).
- `references/config-example-grid.json` — раскладка **grid**: сетка в 3 колонки, по желанию `wm` (название бренда) на карточке, бейдж `note`, плитка `gift` с подарком.

Правила дизайна, которые хорошо сработали:
- До 6 товаров (+ плитка с подарком). Если в письме больше — выбери самые большие скидки / самые известные товары.
- Шаблон заголовка: `<Тема><br>по <em>выгодной</em> цене` — коротко, 2 строки. Надзаголовок: `эмодзи Тема в KSP`. Строка брендов: названия брендов или «+N% поверх акций».
- Подбери тему под категорию (розовая ✿ для косметики, серо-голубая ✦/⚙ для инструментов/бритья и т.п.) — меняй только нужные ключи темы.
- Название на карточке должно влезать в одну строку, размер/описание — желательно тоже: сокращай («Санскрин SPF50+», «Гель для бровей» + «Super Lock, 7 мл») и используй `&nbsp;`, чтобы единицы не отрывались от чисел.
- Красный круг сам считает максимальную скидку; товары без фото пропускаются автоматически.

**Всегда смотри на готовый PNG** (Read) перед отправкой: нет ли переносов в названиях, обрезанного текста, чужого фото на карточке. Исправь и отрендерь заново.

## 5. Отдай результат

1. `git add ksp-<тема>-promo && git commit` (понятное сообщение) и `git push -u origin <текущая ветка>`. PR не открывай, если не просят.
2. Отправь PNG через `SendUserFile` (display: render).
3. Коротко ответь на языке пользователя: что на картинке, что было предположено или чего не хватает, и предложи версию для WhatsApp, если её ещё не было.

Когда пользователь потом что-то исправляет (цену, название, новое фото), обнови `config.json`, отрендерь, закоммить, запушь, отправь заново — и исправь то же самое в тексте, если ты его уже давал.
